# Инструкции для агентов

## Цветовые CSS-токены

- Перед добавлением цветового токена проверь существующую тему UI и используй токен с подходящей смысловой ролью.
- Общие для UI и приложения цвета храни в теме UI под префиксом `--ui-`. В стилях компонентов указывай сначала токен переопределения приложения `--app-*`, затем соответствующий токен UI как fallback: `var(--app-..., var(--ui-...))`.
- Не сопоставляй токены только по совпадающему значению. Токены разных смысловых ролей должны оставаться отдельными, даже если сейчас содержат одинаковый цвет.
- Если цвет относится только к host и подходящего токена UI нет, объяви его в `:root` глобальных стилей host под префиксом `--app-` и используй в стилях через `var(--app-...)`.
- Храни конкретные значения цветов в объявлениях токенов. В стилях используй токены вместо повторяющихся цветовых литералов.
- Переопределяй `--app-*` на корневом элементе приложения или на контейнере, область которого нужно изменить. Токены `--ui-*` задают значения темы UI по умолчанию.
